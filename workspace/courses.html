주차별 커리큘럼

프로젝트별 상세 커리큘럼

각 프로젝트는 4주 과정이며, 매주 이론 + 실습 + 과제로 구성됩니다

주차 강의 주제 주요 내용
1주 파이썬 데이터 분석 환경 구축 주피터 노트북 설치 및 설정, 판다스 DataFrame 기초, 데이터 불러오기 (CSV·Excel)
실습: 공공데이터 포털 데이터 로딩
2주 탐색적 데이터 분석 (EDA) 결측값·이상값 탐지 및 처리, describe() / info() / value_counts(), 상관관계 분석
실습: 타이타닉 데이터 EDA
3주 데이터 시각화 맷플롯립 기본 차트 (선·막대·산점도), 시본 히트맵·pairplot, 인사이트 스토리텔링
실습: 판매 데이터 대시보드 제작
4주 프로젝트 1 완성 & 발표 데이터 전처리 파이프라인 정리, 분석 리포트 작성, GitHub 업로드, 코드 리뷰
과제: 개인 데이터셋 EDA 리포트 제출
주차 강의 주제 주요 내용
5주 머신러닝 개요 & 분류 기초 지도학습 vs 비지도학습, 훈련/검증/테스트 분리, 로지스틱 회귀 원리와 구현
데이터: 텔레콤 고객 이탈 데이터셋
6주 의사결정 트리 & SVM 의사결정 트리 시각화 및 깊이 조절, SVM 커널 트릭 이해, 특성 중요도 분석
실습: 3가지 모델 성능 비교표 작성
7주 모델 평가 & 하이퍼파라미터 튜닝 정밀도·재현율·F1·ROC-AUC, 혼동 행렬 해석, GridSearchCV로 최적 파라미터 탐색
실습: 이탈 고객 예측 모델 최적화
8주 프로젝트 2 완성 & 발표 전처리 → 모델링 → 평가 파이프라인 완성, 비즈니스 인사이트 도출, GitHub 포트폴리오 정리
과제: 이탈 고객 감소 전략 보고서 제출
주차 강의 주제 주요 내용
9주 랜덤 포레스트 & 앙상블 입문 배깅 원리, 랜덤 포레스트 구조 및 구현, 특성 중요도로 변수 선택
데이터: 비만도 분류 데이터셋 (WHO 기준)
10주 다중 분류 & 클래스 불균형 다중 클래스 분류 전략 (OvR / OvO), SMOTE 오버샘플링, 클래스 가중치 조정
실습: 비만 단계 5단계 분류 모델 구축
11주 군집 분석 (K-Means & PCA) K-Means 알고리즘 원리, 엘보우 기법으로 최적 K 선정, PCA로 2D 군집 시각화
실습: 건강 데이터 군집별 특징 분석
12주 프로젝트 3 완성 & 발표 분류 + 군집 복합 분석, 건강 위험군 식별 보고서, 교차 검증으로 일반화 성능 확인
과제: 비만 예방 정책 제안 데이터 보고서
주차 강의 주제 주요 내용
13주 XGBoost & LightGBM 부스팅 원리 (Boosting vs Bagging), XGBoost 파라미터 이해, LightGBM 빠른 학습 원리
실습: 이전 프로젝트 데이터로 앙상블 성능 비교
14주 Optuna 하이퍼파라미터 최적화 베이지안 최적화 원리, Optuna 스터디 설정 및 시각화, 조기 종료 콜백으로 과적합 방지
실습: LightGBM + Optuna 자동 튜닝 파이프라인
15주 생성형 AI API 연동 OpenAI / Claude API 기초, 머신러닝 결과를 프롬프트로 변환, 분석 결과 자동 해석 시스템 구축
실습: 고객 이탈 분석 결과 → AI 해석 리포트 자동 생성
16주 최종 프로젝트 발표 & 포트폴리오 완성 4개 프로젝트 GitHub 정리, README 작성, 최종 발표, 강사 코드 리뷰 및 피드백
결과물: 취업용 ML 포트폴리오 GitHub 저장소 완성

🙋 수강 대상

  • 파이썬 기초를 배웠지만 실제로 뭔가 만들어본 경험이 없는 분
  • 데이터 분석·AI 직무로 전환을 준비 중인 직장인
  • 포트폴리오에 ML 프로젝트를 추가하고 싶은 취준생
  • 실무에서 데이터를 다루는 기획자·마케터로 분석 역량을 키우고 싶은 분
  • 캐글 또는 데이콘 입문을 목표로 하는 분
  • 생성형 AI를 단순 사용이 아닌 개발 관점에서 이해하고 싶은 분

📚 선행 과정 안내

  • 파이썬 변수, 자료형(리스트·딕셔너리·튜플) 이해
  • 조건문(if) / 반복문(for·while) 작성 가능
  • 함수(def) 정의 및 호출 경험
  • 파일 읽기·쓰기 기본 조작 경험
  • 클래스와 객체 개념 이해 (심화 불필요)
