# 코딩 학원 사이트 전체 리뉴얼 Plan Spec

## Context
**인터뷰 결과 요약**
| 항목 | 답변 |
|---|---|
| 사용자 여정 | 방문 → 탐색 → 전환 (전환율 최적화 중심) |
| 백엔드 | 완전 정적 (서버/DB 불필요) |
| 최대 리스크 | 기능 과잉으로 미완성 (scope creep) |
| UX 제1원칙 | 명확함 (Clarity) — 절대 타협 불가 |
| 목표 | 코딩 학원 사이트 **전체 리뉴얼** |

**현재 상태**: `workspace/index.html` — 다크 테마 단일 랜딩 페이지 존재 (완성됨)
**리뉴얼 방향**: 기존 파일을 기반으로 범위를 확장, 강좌 상세 페이지 신규 추가

---

## 전략
기능 과잉 리스크를 감안해 **2개 HTML 파일**로 범위를 엄격히 제한한다.
CLAUDE.md 컨벤션(단일 파일, 순수 HTML/CSS/JS) 유지. 외부 의존성 없음.

---

## 대상 파일

| 파일 | 작업 | 설명 |
|---|---|---|
| `workspace/index.html` | **수정** | 홈 페이지 — 콘텐츠 리뉴얼 |
| `workspace/courses.html` | **신규** | ML 프로젝트 과정 상세 페이지 |

> ⚠️ `curriculum.html` 등 추가 파일은 1차 범위 밖. 요청 없으면 생성 안 함.

## 페이지 구성

### 1. `workspace/index.html` — 홈 (리뉴얼)
기존 7섹션 + footer 구조 유지, 콘텐츠를 PDF 기반으로 교체/업그레이드.

| 섹션 | 변경 내용 |
|---|---|
| 네비게이션 | 기존 유지. "강좌 소개" 링크 → `courses.html` 연결 추가 |
| 히어로 | 타이틀/서브카피를 ML·AI 과정 중심으로 재작성. CTA: "무료 상담 신청" |
| 통계 | 수치 유지 (12,000+ / 98% / 42개 / 4.9점) |
| 강좌 카드 | ML 프로젝트 4단계(Project 1~4) 카드로 교체. "자세히 보기" → `courses.html` 링크 |
| 특징/장점 | 실제 교육 방식 반영: 메모장 코드 작성, 카카오 오픈채팅, 구글 클래스룸 과제 |
| 수강생 후기 | 텍스트만 교체 (실제 과정 분위기 반영) |
| CTA 배너 | "AI 파이썬 1-3 선행 과정 이수 후 수강" 안내 문구 추가 |
| 푸터 | `courses.html` 링크 추가 |

### 2. `workspace/courses.html` — ML 프로젝트 과정 상세 (신규)
PDF(`머신러닝_프로젝트_PR.pdf`) 콘텐츠 전체를 시각화.

| 섹션 | 내용 |
|---|---|
| 히어로 | 과정명, 한줄 소개, "수강 신청" CTA |
| AI 진화 로드맵 | 초기AI → 머신러닝 → 딥러닝 → 생성형AI 타임라인 |
| 4단계 로드맵 | STEP 1~4 카드 (아이콘 + 목표) |
| 커리큘럼 탭 | 프로젝트1~4 탭 전환, 일차별 강의 내용 테이블 |
| 프로젝트 예시 | 고객 이탈 예측 / 비만 단계 분석 스크린샷 설명 카드 |
| 강의 운영 방식 | 3개 블록: 코드 직접 작성 / 카카오 채팅방 / 구글 클래스룸 과제 |
| 수강 대상 & 선행과정 | 체크리스트 + "AI 파이썬 1-3" 선행 강조 |
| CTA | "무료 상담 신청" 버튼 (앵커 or tel/mailto) |

### `workspace/courses.html` 신규 생성 섹션
1. **히어로** — 과정명, 메타정보(16주·프로젝트4개·메모장코딩·카카오채팅), "수강 신청" CTA

6. **강의 운영 방식** — 메모장 코딩 / 카카오 채팅방 / 구글 클래스룸 3블록
7. **수강 대상 & 선행과정** — 체크리스트 + "AI 파이썬 1-3" 경고 박스
8. **CTA** — "무료 상담 전화하기"
