# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a frontend-focused learning/course workspace. Projects are self-contained and typically built with plain HTML, CSS, and JavaScript (no build tools or package managers).

## Structure

- `calculator/` — 3D-styled calculator web app (single `index.html`)
- `workspace/` — working directory for new projects

## Running Projects

Open any `index.html` directly in a browser — no build step or server required.

## Language

모든 응답, 설명, 결과값은 반드시 한글로 작성한다.

## Conventions

- Single-file projects: HTML + `<style>` + `<script>` all in one `.html` file
- No frameworks, bundlers, or external dependencies unless explicitly requested
- CSS uses custom properties and modern layout (Grid, Flexbox)
